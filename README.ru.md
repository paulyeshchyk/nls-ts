
# nls-ts

**Инструмент для автоматизации локализации в расширениях VS Code**

Расширение помогает быстро извлекать строки в NLS (Natural Language Support) с автоматическим созданием абстрактных ключей и развертыванием автономной инфраструктуры локализации прямо в вашем проекте.

## Возможности

- **Два режима извлечения строк:**
- **(string)** - простая строка с вызовом общего транслятора: `translate('key')`
- **(typedef)** - строго типизированная структура с автодополнением свойств: `translate(nls_ts.key.subkey)`
- **Автоматическое создание инфраструктуры:** при первом запуске расширение само добавит в проект легковесный рантайм-лоадер `nls_loader.js`.
- **Умное обновление файлов переводов:** автоматическое создание и наполнение `package.nls.json` новыми ключами.
- **Генерация дерева ключей:** автоматическая сборка файла `nls_ts.js` с вложенной объектной структурой на основе точек в имени ключа.
- **Поддержка плейсхолдеров:** строки вида `${variable}` автоматически преобразуются в шаблоны с аргументами: `translate(key, variable)`.
- **Чистый код:** автоматическое добавление всего одной строки `require` для импорта структуры и функции перевода в целевой файл.

## Как использовать

1. Выделите текст, который хотите локализовать.
2. Нажмите `Ctrl + .` (или `Cmd + .` на macOS) для вызова меню Quick Fix.
3. Выберите один из вариантов:
   - **NLS: Create Key-Value (string)**
   - **NLS: Create Key-Value (typedef)**

### Важный шаг: Инициализация

При первом использовании расширение добавит в корень вашего проекта файл `nls_loader.js`. Чтобы локализация заработала в рантайме, вам необходимо один раз инициализировать её в главном файле вашего расширения (обычно `extension.js`):

```js
const { initNls } = require('./nls_loader');

function activate(context) {
// Инициализируем локализацию перед регистрацией команд
initNls(context);
// Дальше ваш код активации...
}
```

### Пример работы (в режиме typedef)

Выделили в коде:

```js
"Добро пожаловать, ${userName}!"
```

Ввели ключ в Input Box: `greeting.welcome`
Результат в файле:

```js
const { nls_ts, translate } = require('../../nls_ts.js');

translate(nls_ts.greeting.welcome, userName)
```

В автогенерируемом файле `nls_ts.js` появится:

```js
const { translate } = require('./nls_loader');

const nls_ts = {
greeting: {
welcome: "greeting.welcome"
}
};

module.exports = { nls_ts, translate };
```

### Создаваемые файлы

`nls_loader.js` - изолированный рантайм-хелпер. Создается один раз, управляет загрузкой JSON-файлов в зависимости от текущего языка интерфейса VS Code.
`package.nls.json` - основной файл flat-переводов.
`nls_ts.js` - объектное дерево ключей (создается и обновляется только при выборе режима typedef).

## Установка

Установите расширение из VS Code Marketplace.
Или склонируйте репозиторий и выполните:

```bash
npm install && npm run compile
```

## Команды

`nls_ts.createKeyValueString` - извлечь строку в формате плоского текстового ключа.
`nls_ts.createKeyValueTypedef` - извлечь строку с генерацией древовидной структуры свойств.

## Рекомендации

Используйте (`typedef`) режим для средних и больших проектов - это обеспечивает навигацию по ключам через `Ctrl + Click` и полноценное автодополнение (IntelliSense) без риска опечататься в строке.

Не редактируйте файлы `nls_loader.js` и `nls_ts.js` вручную - они поддерживаются и пересобираются расширением автоматически.
